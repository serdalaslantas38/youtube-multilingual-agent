YouTube Multilingual Publishing Agent

YouTube Multilingual Publishing Agent is a creator-operated localization and publishing workflow application designed for the YouTube channel HayataDairPüfNoktalar (@orchidhacks).

What This Application Does

  • Discovers videos and inspects Turkish source subtitle tracks from the authenticated creator's YouTube channel via the official YouTube Data API v3.
  • Translates and validates video titles, descriptions, and SRT subtitle tracks across 48 target languages with human-in-the-loop quality review.
  • Publishes approved localized metadata (videos.update) and subtitle tracks (captions.insert) back to the creator's own YouTube videos with post-write verification.

Data Protection & Google API Compliance

This application accesses YouTube Data API v3 solely on behalf of the authenticated channel owner. OAuth 2.0 refresh tokens are encrypted at rest with Fernet (AES-128-CBC + HMAC-SHA256) and are never shared with third parties or exposed to language models.
