Privacy Policy — YouTube Multilingual Publishing Agent

Effective Date: November 2026

This Privacy Policy explains how YouTube Multilingual Publishing Agent accesses, uses, stores, and protects Google and YouTube user data when authorized by a YouTube channel owner.

1. Google & YouTube API Services Disclosure

YouTube Multilingual Publishing Agent uses YouTube API Services and complies with the Google API Services User Data Policy, including the Limited Use requirements, and the YouTube API Services Terms of Service. Please also review the Google Privacy Policy.

2. Data We Access

  • YouTube Channel & Video Metadata: Channel ID, channel title, uploads playlist items, video titles, descriptions, localizations, and caption tracks via scope https://www.googleapis.com/auth/youtube.force-ssl.
  • Operator Identity: Basic account email address (openid, email) to verify authorized dashboard operators.

3. How We Use and Store Your Data

  • Data is used exclusively to generate, review, validate, and publish multilingual titles, descriptions, and closed captions for the authorized YouTube channel.
  • OAuth 2.0 refresh tokens are encrypted at rest using symmetric authenticated encryption (Fernet) and stored only in the operator's database.
  • We never sell, rent, or transfer Google user data to third parties, and we never expose OAuth tokens or secrets to frontend clients or external LLMs.

4. Revoking Access & Data Deletion

You may revoke this application's access to your Google Account at any time via the Google Security Settings page. Upon revocation or request, stored OAuth credentials and cached channel records are deleted immediately.
